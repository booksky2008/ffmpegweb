================================================================
  视频 <-> 音频转换工具(本地版)
================================================================

一个双击就能用的小工具:选文件、选格式、点「开始转换」。
转换由你电脑上的 ffmpeg 完成,文件不会上传到任何地方,
没有网络也能用。

仅支持 Windows(7 / 10 / 11)。


----------------------------------------------------------------
一、文件说明
----------------------------------------------------------------

  视频音频转换.hta   主程序,双击运行
  ffmpeg.exe         ffmpeg 可执行文件(需要你自己下载,见下文)
  readme.txt         本说明

.hta 是 Windows 自带的"HTML 应用程序",本质是一个有权限运行本机
程序的网页,由系统自带的 mshta.exe 打开,不用安装任何东西。


----------------------------------------------------------------
二、准备 ffmpeg(二选一)
----------------------------------------------------------------

先下载 ffmpeg(Windows 版):

  https://www.gyan.dev/ffmpeg/builds/
    -> 下载 ffmpeg-release-essentials.zip

  或 https://github.com/BtbN/FFmpeg-Builds/releases
    -> 下载 win64-gpl 的 zip

解压后,在 bin 文件夹里找到 ffmpeg.exe。

【方式 A:放在一起(最简单,推荐)】
  把 ffmpeg.exe 复制到「视频音频转换.hta」所在的文件夹,
  两个文件放在一起即可。放在同级的 bin 子文件夹里也行。
  不需要设置任何环境变量,整个文件夹可以拷到别的电脑或U盘使用。

【方式 B:设置环境变量】
  1. 把解压出来的 bin 文件夹放到固定位置,例如 D:\ffmpeg\bin
  2. 按 Win+R,输入 sysdm.cpl 回车
  3. 「高级」->「环境变量」->在「Path」里点「新建」,
     填入 D:\ffmpeg\bin,一路确定
  4. 重新打开命令提示符,输入 ffmpeg -version,
     能看到版本号就说明设置成功

程序启动时的查找顺序:
  1) 和本程序同一文件夹里的 ffmpeg.exe
  2) 同一文件夹下 bin 目录里的 ffmpeg.exe
  3) 系统 PATH 环境变量里的 ffmpeg
两种方式同时存在时,优先使用放在一起的那个。

标题旁会显示版本号和来源,例如 v9.0.2 (local):
  local 表示用的是放在一起的 ffmpeg.exe,env 表示用的是环境变量里的。
如果提示"未找到转换组件",请按上面的方法检查。


----------------------------------------------------------------
三、使用步骤
----------------------------------------------------------------

  1. 双击「视频音频转换.hta」。
     如果 Windows 弹出安全提示,选「打开」/「运行」。
  2. 点「源文件」选择要转换的文件(mp4、mkv、avi、mov、mp3、wav 等
     ffmpeg 支持的格式都可以)。选好后会显示时长、分辨率、总码率。
  3. 选择「输出格式」,例如 mp3。
  4. (可选)修改保存的文件名、保存位置、截取范围、分辨率和码率。
  5. 点「开始转换」。转换期间会显示已用时间,可随时点「停止」。
  6. 完成后点「打开所在文件夹」,会直接定位到输出文件。


----------------------------------------------------------------
四、功能说明
----------------------------------------------------------------

【输出格式】
  mp3 m4a ogg wav flac mp4 mkv webm gif

【保存的文件名】
  默认和源文件同名,只改后缀,可以自己改。
  如果输出格式和源文件相同(例如 mp4 转 mp4),会自动加上
  "_转换",避免覆盖源文件。输出文件不能和源文件同名同位置。

【保存到文件夹】
  默认保存在源文件所在的文件夹。
  点「浏览…」选择其他文件夹,点「同源文件夹」恢复默认。

【截取范围】
  填写开始和结束时间,默认「0 到 全部」。
  时间格式可以是:
      90          (90 秒)
      1:30        (1 分 30 秒)
      01:02:03.5  (1 小时 2 分 3.5 秒)
  结束时间留空表示一直到结尾。
  提示:选了「不重新编码」时,截取起点会对齐到附近的关键帧,
  可能和填写的时间有一点偏差;重新编码的则是精确的。

【分辨率 / 码率下拉框】
  选择后,下方的「转换参数」会自动生成。
  各格式显示的选项:

    输出格式          分辨率   视频码率   音频码率
    mp4 / mkv / webm   有       有         有
    gif                有       无         无
    mp3 / m4a / ogg    无       无         有
    wav / flac         无       无         无(无损格式)

  - 分辨率:按比例缩放到"不超过所选尺寸",画面不会变形,
    竖屏视频也适用。也可以选「自定义…」填写如 1000x562。
  - 视频码率 / 画质:
      不重新编码   直接复制,最快、画质无损,但不能改分辨率
      高画质       文件较大
      标准画质     推荐
      小体积       画质较低
      固定码率     500 ~ 8000 kbps,文件大小可预估
  - 音频码率:默认,或 64k ~ 320k,数字越大音质越好、文件越大。

【转换参数】
  由上面的选项自动生成,一般不用改。
  需要高级设置时可以直接修改,点框下方「参数怎么改?」
  可查看常用参数的说明。注意:
    1. 这里的参数会完整替换预设,不是追加。
    2. 参数要和输出格式匹配(例如输出 mp3 不要写视频参数)。
    3. 文件名、保存位置、起止时间在上面单独填,不要写进这里。
    4. 手动改过之后,再调整下拉框会重新覆盖这里的内容。
    5. 改乱了点「恢复预设」即可。


----------------------------------------------------------------
五、常见用法示例
----------------------------------------------------------------

  mp4 提取成 mp3
      输出格式选 mp3 -> 开始转换

  只要视频中 1 分 30 秒到 3 分钟的一段
      截取范围填 1:30 到 3:00

  1080p 视频压缩成 720p 小文件
      输出格式 mp4 -> 分辨率 1280x720 -> 视频码率「小体积」

  把视频做成动图
      输出格式 gif -> 截取一小段(几秒)-> 分辨率选 640x360
      (gif 体积很大,建议只转几秒)

  视频换容器、不损失画质
      输出格式 mkv 或 mp4 -> 视频码率「不重新编码」


----------------------------------------------------------------
六、常见问题
----------------------------------------------------------------

Q: 提示"未找到 ffmpeg"?
A: 把 ffmpeg.exe 放到本程序同一文件夹;或检查环境变量 Path 是否
   正确(在命令提示符里能运行 ffmpeg -version 才算成功),
   设置环境变量后需要重新打开本程序。

Q: 双击没反应,或被杀毒软件拦截?
A: .hta 能运行本机程序,部分杀毒软件会提示风险,属于类型误报。
   本程序没有联网功能,代码是明文的,可以用记事本打开查看。
   如果被拦截,请把它加入信任/白名单。

Q: 提示"转换失败"?
A: 窗口会显示 ffmpeg 的错误信息。常见原因:
   - 参数和输出格式不匹配(点「恢复预设」试试)
   - 源文件已损坏或不是音视频文件
   - 输出文件被其他程序占用
   - 磁盘空间不足

Q: 转换很慢?
A: 视频重新编码本来就比较耗时,取决于电脑性能和视频长度。
   只想换格式可以选「不重新编码」,速度会快很多。

Q: 文件名里有中文或空格可以吗?
A: 可以。文件名里不能包含 \ / : * ? " < > | 这些符号。

Q: 能在 Mac / Linux 上用吗?
A: 不能,.hta 只支持 Windows。

Q: 点「停止」是怎么停的?
A: 会结束系统里所有 ffmpeg.exe 进程。如果你同时在用别的方式
   运行 ffmpeg,也会被一起结束,请留意。


----------------------------------------------------------------
七、注意事项
----------------------------------------------------------------

  - 转换过程中请不要关闭程序窗口。
  - 程序会在系统临时文件夹(%TEMP%)里写入少量日志文件:
    ffconv.log、ffconv.done、ffver.txt、ffprobe.txt,
    可以随时删除,不影响使用。
  - 目标文件已存在时会先询问是否覆盖。
  - 源文件不会被修改。
  - ffmpeg 本身遵循其各自的开源协议,请从官方或可信渠道下载。
